# 🎉 年会抽奖系统

单页 HTML 应用，无需安装任何依赖，浏览器打开即可使用。

## 功能

- **参与者管理** — 手动添加/删除参与者姓名
- **单一奖品输入** — 每次抽奖输入一个奖品
- **滚筒抽奖动画** — 名字滚动带景深透视效果（中间最大、两边缩小）
- **自然减速停止** — 无强制对齐，谁在黄框里谁中奖
- **全屏中奖弹窗** — 中奖者大号金色展示 + 彩带特效
- **抽取记录** — 查看所有已抽奖项
- **一键模拟** — 快速填充测试数据

## 使用

直接在浏览器打开 `index.html` 即可，零配置。

1. 输入参与者姓名
2. 填写本轮奖品
3. 点击「开始抽奖」
4. 再点一次「停止」减速出结果
5. 全屏弹窗展示中奖信息，点击 ✕ 关闭

## 技术

纯 HTML + CSS + JavaScript，无任何外部依赖。
